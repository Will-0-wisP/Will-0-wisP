### 2. Create your profile repository

Create a GitHub repository with the exact same name as your GitHub username.

Example:

```txt
github.com/YOUR_GITHUB_USERNAME/YOUR_GITHUB_USERNAME
```

Add this `README.md` file to the root of that repository.

### 3. Enable GitHub Actions

For contribution snake and 3D contribution graph, add the required workflow files inside:

```txt
.github/workflows/
```

### 4. Give workflow write permission

Go to:

```txt
Settings → Actions → General → Workflow permissions
```

Enable:

```txt
Read and write permissions
```

### 5. Push changes

After pushing, the README will render on your GitHub profile page.
